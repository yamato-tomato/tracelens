# TraceLens

Ad-free AR tracing web app: overlay any image on your camera feed and trace it onto paper.
Single static page, works offline once loaded, no tracking.

Open on phone → Share → Add to Home Screen.

## Built-in reference library

180 figures, sorted by body region, cropped from five public-domain books, scanned on the Internet Archive:

- E. G. Lutz, *Practical Art Anatomy* (1918): archive.org/details/practicalartanat00lutz
- John Marshall, *Anatomy for Artists* (1878), Wellcome Collection (Public Domain Mark): archive.org/details/b21688710
- *Duval's Artistic Anatomy*, revised edition (1905): archive.org/details/duvalsartistican00duva
- George B. Bridgman, *Constructive Anatomy* (1920): archive.org/details/constructiveanat00brid
- Richard G. Hatton, *Figure Drawing and Composition* (1895): archive.org/details/figuredrawingcom00hatt

The page was auto-cropped to the figure, the paper tint was removed, and the image was converted to grayscale. Each entry's credit shows the source book and the scan page.
